# Windows 98 logo

`windows-98.svg` is the unmodified stacked Windows 98 logo, attributed to Microsoft.

Source: https://commons.wikimedia.org/wiki/File:Windows_98_stacked_logo.svg

Asset: https://upload.wikimedia.org/wikipedia/commons/5/59/Windows_98_stacked_logo.svg

Retrieved 2026-09-29. The source labels the artwork PD-textlogo and identifies it as a trademark.
Used in the nostalgic boot splash at the project owner's explicit request. The sky and activity
strip are a web adaptation, not an extracted original Windows boot bitmap. The rest of the site
retains the Setac² design system.
